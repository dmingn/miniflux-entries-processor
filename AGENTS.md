# AGENTS.md

This document provides project-specific guidelines for AI coding agents.

## Development and checks

For setting up the Python environment and running checks, see [`docs/how-to/develop-and-test.md`](docs/how-to/develop-and-test.md).

Before submitting changes, run `make format-and-check`. This command runs formatting, linting, type checking, and unit tests.

## Language

All code, documentation (including code comments), and commit messages MUST be written in English.

## Naming conventions for rule components

When adding or renaming conditions and actions, see [`docs/how-to/add-rule-components.md`](docs/how-to/add-rule-components.md).
